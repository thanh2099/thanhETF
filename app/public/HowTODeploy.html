Option 1 — Netlify Drop (The 60-Second No-Code Method)
Zero Code · Drag & Drop

This is the fastest, simplest way to get your website online right now. You don't need any terminal commands, GitHub account, or server setup.

1
Locate Your 'dist' Folder on Your PC
1. Open Windows File Explorer (or press Windows Key + E).
2. Navigate to this exact folder on your computer:
C:\Users\Thanh\Desktop\DecodeETFClone\app\dist
💡 Good news: We have already compiled and generated this dist folder for you! It contains your complete optimized HTML, CSS, JavaScript, and assets ready to go live.
2
Open Netlify Drop in Your Web Browser
Open Google Chrome or Microsoft Edge and visit:
https://app.netlify.com/drop Open Link ↗
You will see a big dotted area that says: "Drag and drop your site folder here".
3
Drag and Drop the 'dist' Folder
1. Drag the dist folder directly into the dotted box in your browser.
2. Release your mouse button.
3. Netlify will upload and process the files in about 15–20 seconds.
4
Your Site Is Live Worldwide!
Netlify will immediately show a green checkmark with your free public URL (e.g., https://happy-mountain-12345.netlify.app).

Want a custom name?
1. Click Site configuration → Change site name.
2. Type in thanhetf or your chosen project name → Click Save.
3. Your permanent URL will now be: https://thanhetf.netlify.app!
Option 2 — Vercel + GitHub (Zero-Config Auto-Deploy)
Automated · Continuous Integration

This is the developer standard. Whenever you make code edits or update ETF data in the future, Vercel automatically re-builds and updates your live website instantly.

1
Push Your Code to GitHub
If you are starting fresh on a new machine, configure your git identity first:
git config --global user.name "thanh" ; git config --global user.email "thanh@example.com"
Then, push the repository to GitHub:
git add . ; git commit -m "Deploy ThanhETF platform" ; git branch -M main ; git push -u origin main
2
Import into Vercel (Zero Settings Needed!)
1. Visit vercel.com/new and sign in with GitHub.
2. Under Import Git Repository, click Import next to thanh2099/thanhETF.
3. Leave all settings as default! You do NOT need to change the Root Directory or Build Command. We pre-configured a root vercel.json file that automatically builds app/dist for you.
4. Click the blue Deploy button.
✨ Zero-Config Automation:
You can keep Root Directory set to ./ (default). Our root vercel.json script automatically compiles the app/ folder, handles all SPA client-side routes, and wires the live Yahoo Finance serverless API.
3
Where to Find Project Settings (If Ever Needed)
In Vercel's latest interface layout:
⚙️ Vercel Navigation Guide:
• In your project dashboard, click Settings at the very bottom of the left sidebar.
• Look at the tabs under Settings in the left sidebar: Click Build and Deployment (the 2nd tab right under General).
• This is where Vercel places Framework Preset, Build Command, Output Directory, and Root Directory if you ever want to view or customize them.
4
