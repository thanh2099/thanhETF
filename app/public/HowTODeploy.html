ThanhETF Deployment Guide Beginner Tutorial

How to Deploy Your Website to the Internet

A complete, step-by-step beginner guide to publishing your ThanhETF / DecodeETF Clone web project on the public internet. Follow either of the two easy, 100% free hosting options below.

Option 1 — Netlify Drop (The 60-Second No-Code Method)
Zero Code · Drag & Drop

This is the fastest, simplest way to get your website online right now. You don't need any terminal commands, GitHub account, or server setup.

1
Locate Your 'dist' Folder on Your PC
1. Open Windows File Explorer (or press Windows Key + E).
2. Navigate to this exact folder on your computer:
C:\Users\Thanh\Desktop\DecodeETFClone\app\dist
💡 Good news: We have already compiled and generated this dist folder for you! It contains your complete optimized HTML, CSS, JavaScript, and assets ready to go live.
2
Open Netlify Drop in Your Web Browser
Open Google Chrome or Microsoft Edge and visit:
https://app.netlify.com/drop Open Link ↗
You will see a big dotted area that says: "Drag and drop your site folder here".
3
Drag and Drop the 'dist' Folder
1. Drag the dist folder directly into the dotted box in your browser.
2. Release your mouse button.
3. Netlify will upload and process the files in about 15–20 seconds.
4
Your Site Is Live Worldwide!
Netlify will immediately show a green checkmark with your free public URL (e.g., https://happy-mountain-12345.netlify.app).

Want a custom name?
1. Click Site configuration → Change site name.
2. Type in thanhetf or your chosen project name → Click Save.
3. Your permanent URL will now be: https://thanhetf.netlify.app!
Option 2 — Vercel + GitHub (Professional Auto-Deploy)
Recommended · Auto Updates

This is the developer standard. Whenever you make code edits or update ETF data in the future, Vercel will automatically re-build and update your live website instantly.

1
Push Your Code to GitHub
1. Go to github.com/new and create a new repository named DecodeETFClone.
2. In your terminal at c:\Users\Thanh\Desktop\DecodeETFClone, run:
git add . ; git commit -m "Deploy ThanhETF" ; git push -u origin main
2
Connect Vercel to Your GitHub Account
1. Visit vercel.com and sign in with GitHub.
2. Click the Add New... button in the top right → Select Project.
3. Find DecodeETFClone in the list and click Import.
3
Crucial Step: Set Root Directory to 'app'
Because your React code lives in the app subfolder, configure this setting on Vercel:
⚠️ Important Setting:
Next to Root Directory, click Edit → Select or type app → Click Continue.
• Framework Preset: Vite (Auto Detected)
• Build Command: npm run build (Default)
• Output Directory: dist (Default)
4
Click 'Deploy' & Watch the Magic!
1. Click the blue Deploy button.
2. In under 45 seconds, fireworks will appear on screen.
3. You'll get your live link (e.g., https://decode-etf-clone.vercel.app) with automatic global CDN and free HTTPS SSL encryption.
